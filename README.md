# Mothlight

A tiny night-flight arcade game. Gather glowing seeds, chain a streak, and dodge the shadows until dawn.

## Play locally

Open `index.html` in a browser. Move with **WASD** or the **arrow keys**, dash with **Space**, and pause with **P** or **Escape**. On touchscreens, use the on-screen controls.

## Publish with GitHub Pages

The included GitHub Actions workflow deploys the game whenever you push to `main` or `master`, and can also be run manually from the Actions tab. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The published URL appears in the deployment summary.
